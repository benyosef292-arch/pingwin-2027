# אתר צוות וולטורנס 2027 · פינגווין

האתר החי: https://benyosef292-arch.github.io/pingwin-2027/ (GitHub Pages, ענף `main`).
אתר סטטי בלי build: הדפדפן טוען את `index.html` והוא מושך את שאר הקבצים.

## מבנה התיקיות

| תיקייה | מה יש בה |
|---|---|
| `index.html` | שלד הדף בלבד: ה־HTML של כל המסכים ורשימת הקבצים שנטענים, לפי סדר |
| `pages/` | קובץ JS לכל מסך/טאב: לוחות משימות, לו"ז שבועי, ספקים, מחסן, לוח שנה, אנשי קשר... |
| `components/` | חלקים משותפים: תפריט צד, מצגת (deck), אנימציות, ערכת נושא, גיבוי/שחזור |
| `data/` | נתונים ושמירה/טעינה: ה־seed של המשימות, החיבור לגיליון Google‏ (`sheet-api.js`), הסנכרון (`shared-store.js`) |
| `css/` | כל העיצוב, קובץ לכל שכבה, באותו סדר טעינה (הסדר קובע!) |
| `photos/` | תמונות המלונות |
| `tests/` | בדיקת "לפני/אחרי" שמוכיחה שהאתר לא השתנה |
| `tools/` | כלי עזר (הצפנת סיכום המייל) |

הכללים המלאים לעבודה על הקוד: **CLAUDE.md**. כללי העיצוב: **DESIGN.md**.

## נתונים

נתוני הצוות נשמרים בגיליון Google דרך Apps Script web app (הכתובת ב־`data/sheet-api.js`).
את ה־Apps Script עצמו (`site/Code.gs.txt` בתיקיית הפרויקט) בן פורס ידנית — לא לגעת בלי צורך.

## איך בודקים שכלום לא נשבר

```
node tests/snapshot.cjs לפני      # לפני השינוי
node tests/snapshot.cjs אחרי      # אחרי השינוי
node tests/compare.cjs לפני אחרי  # חייב להדפיס: identical
```

הבדיקה פותחת את האתר ב־88 מצבים (כל טאב וכל שקופית × כהה/בהיר × מחשב/טלפון)
ומשווה את הטקסט ואת העיצוב המחושב של כל אלמנט. דורש Node + Playwright.
